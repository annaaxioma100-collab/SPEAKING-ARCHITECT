SPEAKING ARCHITECT — version 1.0

Быстрый просмотр на компьютере: откройте index.html двойным нажатием.
Для установки на Android/iPhone и работы микрофона нужен HTTPS-адрес: разместите содержимое папки на любом статическом HTTPS-хостинге (например GitHub Pages / Netlify / Cloudflare Pages). Откройте адрес в браузере телефона и используйте меню «Добавить на экран Домой» / «Установить приложение».
На iPhone: Safari → Поделиться → На экран «Домой».
На Android: Chrome → меню → Установить приложение или Добавить на главный экран.

После первой загрузки по HTTPS программа может работать без интернета благодаря service worker.

Приложение не подключается к ChatGPT, не требует аккаунта и не отправляет ответы на сервер. История хранится в localStorage на текущем устройстве. Аудиозапись после остановки можно скачать отдельно; она не сохраняется автоматически в журнале.
